# Maintainers

Maintainers review pull requests, cut releases, and guide the project's
direction.

## Current maintainers

- @jadidbourbaki

## Getting in touch

File a [GitHub issue](https://github.com/jadidbourbaki/vetkitten/issues).
See [SECURITY.md](SECURITY.md) for reporting a vulnerability.

## Becoming a maintainer

Reach out to the current maintainers through a GitHub issue.

## Responsibilities

- Review and merge pull requests
- Triage issues
- Guide the technical direction
- Keep the quality gate green
- Release new versions
- Foster a welcoming community
